# Resend Voxgig SDK

This repository contains an attempt to generate a TypeScript SDK for the Resend API using the Voxgig SDK generator and Resend's official OpenAPI specification.

## Project layout

- `resend.yaml` - official Resend OpenAPI specification
- `resend-sdk/` - project generated by the Voxgig SDK tooling
- `resend-sdk/.sdk/` - Voxgig model, definitions, templates, and generation tooling
- `DX_REPORT.md` - notes about the setup, issues encountered, and final result
- `LICENSE` - MIT license

## Setup

```bash
cd resend-sdk/.sdk
npm install
```

The Resend OpenAPI definition was processed with:

```bash
npx voxgig-apidef resend --folder . --def ./def/resend.yaml --prefix ""
```

## Generate

```bash
cd model
npx voxgig-model sdk.aontu
```

The OpenAPI specification was successfully converted into Voxgig's semantic model and Resend entities were generated.

TypeScript SDK generation then stopped because of a missing internal template path:

```text
model/tm/ts/src/feature/test
```

See `DX_REPORT.md` for the full notes and errors.
